# Русская справка сервера 1.0.3

`!help` и `/help` в общем/командном чате; `ultrahc_help` в консоли игрока. Справка не выполняет команды за игрока. Административные темы показываются по действующим правам и работающим плагинам; доступ перепроверяется при выборе темы.

Скомпилировать `ultrahc_help.sma`, установить бинарник в `addons/amxmodx/plugins`. В `plugins.ini` добавить одну строку `ultrahc_help.amxx` после `admin.amxx`, до обработчиков чата/Discord. Файл `ultrahc_help_rules.txt` поместить в `addons/amxmodx/configs`.

Правила владелец пока не предоставил. Шаблон не содержит выдуманных правил; справка сообщает, что текст не опубликован. Добавлять UTF-8, по одному короткому правилу на строку, не более 320 байт; `;` и `#` начинают комментарий. Новый текст читается при следующей загрузке карты.

Источники тем: реальные объявления и регистрация команд сервера, исходники собственных дополнений. Справка охватывает меню ботов, статистику, голосование карты/проходов, общение, голосование ограничения исходящего урона, административное ограничение урона, редактирование надписей/рекламы. Неактивные или недоступные команды скрываются.

Нужны только стандартные AMXX/amxmisc. Размеры меню проверены на лимит 512 байт. Подтверждена загрузка на AMXX 1.9.0.5294; интерфейс и права с реальным клиентом ещё не проверены.

При сборке укажите каталог стандартных include AMXX и имя результата без расширения: `amxxpc.exe ultrahc_help.sma -i<каталог_include> -oultrahc_help -E`. Будет создан `ultrahc_help.amxx`. Найденный локальный компилятор имеет фактическую версию 1.10.0.5461; предупреждения считаются ошибками благодаря `-E`.

Подсказка о ботах рассчитана на [Bot Control 1.3](../bot_control). В справке `/mute` описан как личное отключение голоса по исходнику ChatAdditions v1.9.1, а не как голосование из старого объявления.
