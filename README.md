# Дополнения CS 1.6

Исходники AMX Mod X и связанного Discord-бота. Каждое игровое дополнение находится в своей папке `ultrahc/<название>`: исходник `.sma`, описание `readme.md` и необходимые настройки рядом.

## Новые дополнения

| Дополнение | Версия | Что делает |
| --- | --- | --- |
| [Управление ботами](ultrahc/bot_control) | 1.3 | Меню `!bots`, повторное добавление противников, выбор сложности; старые `!ba`, `!br`, `!bk` сохранены |
| [Меню и справка сервера](ultrahc/server_help) | 1.1.0 | `!pika` — доступные действия, `!help` — оформленная MOTD-справка; выбор игрока для ограничения урона |

В папках указаны установка, зависимости и ограничения. Bot Control 1.3 и предыдущая справка 1.0.3 проверялись загруженными на AMXX 1.9.0.5294. Для нового интерфейса 1.1.0 загрузка и вид в игровом клиенте проверяются отдельно от сборки. Текст правил заполняется владельцем в `ultrahc_help_rules.txt`, готовых выдуманных правил нет.

Приватные серверные настройки и пароли в новые дополнения не входят; компилятор и готовые бинарники здесь не хранятся, как и у остальных игровых дополнений этого репозитория.
