# Меню «Пикабу» и справка 1.2.0

`!pika` / `/pika` — действия сервера. `!help` / `/help` — только справка в MOTD, без игрового меню под окном и после его закрытия. Работают в общем и командном чате; в консоли — `pika` и `ultrahc_help`.

## Меню !pika

| Клавиша | Раздел | Действие |
| --- | --- | --- |
| 1 | Боты | Сразу открывает меню Bot Control: повторное добавление, сложность, управление ботами |
| 2 | Голосования | За досрочную смену карты (RTV), открытие/закрытие проходов, ограничение урона игроку |
| 3 | Статистика CS | Ранг, результаты карты, лучшие игроки, урон и сообщения статистики |
| 4 | Отключить голос для себя | Личное отключение голоса выбранного игрока, не голосование |
| 5 | Помощь | Одна страница MOTD с внутренними ссылками |
| 6 | Администратору | Разделы «Урон игрока», «Надписи», «Реклама», если есть доступ |
| 0 | Выход | Закрывает меню |

Недоступные разделы скрыты, номера оставшихся не сдвигаются. В списках до пяти действий: 7 — предыдущая страница, 8 — следующая, 9 — к разделам, 0 — выход. Цвета выделяют номера и заголовки; украшения не мешают читать названия.

RTV означает ваш запрос досрочного голосования, а не немедленную смену карты. Урон выбирается голосованием после выбора игрока; исходный плагин требует регистрацию Steam ID в SQL/Discord и проверяет текущие ограничения. Меню не обещает доступность голосования, если эти дополнительные условия не выполнены.

Администратору доступны выбор игрока и доли исходящего урона, снятие своего ограничения и разрешённые действия редакторов. Снятие административного множителя не отменяет результат голосования. Команды с обязательным свободным текстом (`slcreate "Текст"`) и удержанием клавиши (`bind p +place_ad`) не запускаются ошибочно без параметров.

## Справка без меню

Короткие разделы «Боты», «Голосования», «Личное», «Администратору» показываются по наличию дополнений и правам. Ссылки наверху и «Наверх» перемещают внутри того же HTML-документа. Они не запускают игровые команды: для действий есть `!pika`. «Наш Discord» — единственная внешняя ссылка, открывается только по нажатию; сама справка не загружает внешние ресурсы.

Использованы тёмный фон, светлый текст, отдельные заголовки и простая HTML/CSS-разметка без JavaScript, картинок и веб-хостинга. Удалены HLstatsX, подсказки о клавишах чата и пустой раздел правил. Установленная статистика CS (StatsX RBS) сохранена. Страниц `!help 2` и скрытого меню перелистывания больше нет.

Вся страница должна помещаться в **1450 байт UTF-8**, включая оформление; передача файла вместо строки не обходит [лимит MOTD AMXX](https://github.com/alliedmodders/amxmodx/blob/master/plugins/include/amxconst.inc). Поддержка HTML и якорных ссылок зависит от игрового клиента. Проверка HTML в обычном браузере не заменяет вход в CS.

### Необязательные правила

Утверждённого текста пока нет; файл `ultrahc_help_rules.txt` содержит только комментарии и не создаёт пустой раздел. При добавлении правил в этом же MOTD появляются раздел и внутренняя ссылка.

Формат: UTF-8, одно короткое правило на строку; `;` и `#` — комментарии. Защитные пределы чтения (64 правила, до 320 байт на строку, 256 физических строк) **не означают**, что такой объём поместится в одну страницу. Для правил остаётся только свободный объём до общего лимита 1450 байт, особенно мало в варианте администратора. Длинный текст требует отдельного решения с подтверждённой веб-страницей, а не увеличения массива.

Если готовый HTML не помещается, плагин пишет ошибку в журнал и сообщает о слишком длинных правилах вместо показа обрезанного документа. Он никогда не публикует частичное правило. После изменения текста проверьте оба варианта справки при следующей загрузке карты. Не копируйте шаблон поверх своих правил.

## Установка и безопасность

Скомпилируйте `ultrahc_help.sma`, сохраните прежний бинарник и замените только `addons/amxmodx/plugins/ultrahc_help.amxx`. Отдельный плагин `pika` не нужен. В `plugins.ini` должна быть ровно одна строка `ultrahc_help.amxx` после `admin.amxx`, перед обработчиками чата/Discord. Активируйте при безопасной смене карты и проверьте версию в `amxx plugins`.

Каталог не сканирует произвольные команды всех плагинов. Для известных действий проверяются загруженный владелец и текущие права, повторно — перед выполнением. Дополнительные проверки самого дополнения сохраняются. Цели запоминаются по userid, а не переиспользуемому слоту.

Вызов через [amxclient_cmd](https://www.amxmodx.org/api/amxmodx/amxclient_cmd) выполняется от имени игрока с обычными проверками исходного плагина. Клиентские привязки не меняются. Меню ботов не перекрывается меню `!pika`. Открытие справки закрывает текущее игровое меню, но не уничтожает чужой объект меню.

Discord-бот, его настройки и `ultrahc_discord.amxx` этим обновлением не заменяются. Перехватываются только служебные `!help`, `/help`, `!pika`, `/pika`; обычный чат передаётся следующим обработчикам.

## Сборка и проверка

Нужны стандартные AMXX/amxmisc с `amxclient_cmd`; рабочий сервер использует AMXX 1.9. Компилятор, проверенный локально: 1.10.0.5461.

`amxxpc.exe <абсолютный путь к ultrahc_help.sma> -i<каталог include> -o<абсолютный путь результата без расширения> -E`

`python -X utf8 test_ui.py` проверяет 128 сочетаний наличия модулей/прав, общий размер документа, все внутренние ссылки, экранирование правил, размеры меню и каталог запускаемых действий. `--preview-dir <новый каталог>` создаёт примеры HTML. Это модель текстового контракта по исходнику, не эмулятор Pawn или клиента CS.

Проверка в игре: открыть `!help` при открытом `!pika` и меню ботов; нажать внутреннюю ссылку, закрыть MOTD — никакого игрового меню оставаться не должно. В `!pika` проверить названия голосований, навигацию, обычного игрока и администратора, серийное добавление ботов. Само голосование проверять только согласованно, не запускать ради проверки текста.

Приёмы оформления взяты из штатных меню AMXX: [cmdmenu](https://github.com/alliedmodders/amxmodx/blob/master/plugins/cmdmenu.sma), [mapsmenu](https://github.com/alliedmodders/amxmodx/blob/master/plugins/mapsmenu.sma), [restmenu](https://github.com/alliedmodders/amxmodx/blob/master/plugins/cstrike/restmenu.sma). Семантика команд сверена с исходниками собственных дополнений и регистрацией команд сервера.
