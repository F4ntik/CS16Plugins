# Меню «Пикабу» и справка 1.1.0

`!pika` / `/pika` — меню доступных действий. `!help` / `/help` — русская справка в оформленном MOTD-окне. Работают в общем и командном чате; в консоли — `pika` и `ultrahc_help`.

## Действия в меню

Команды игрока, справка, правила и, при наличии прав, команды администратора. Показываются действия из известного каталога с работающим плагином и подходящими правами; произвольные команды сторонних плагинов автоматически не добавляются.

- Меню ботов, статистика/рейтинги, личное отключение голоса, голосование за карту и проходы.
- Голосование за уменьшение урона — через выбор игрока. Исходный плагин по-прежнему требует SQL/Discord-регистрацию и проверяет, можно ли сейчас начать голосование.
- Администратору: выбор игрока и доли урона, снятие своего ограничения, доступные действия редакторов надписей/рекламы.

Права и доступность проверяются повторно перед запуском. Игрок запоминается по userid, а не переиспользуемому слоту. Вызов через [amxclient_cmd](https://www.amxmodx.org/api/amxmodx/amxclient_cmd) проходит обычные проверки исходного плагина от имени выбравшего действие игрока, не от серверной консоли. Клиентские привязки клавиш не меняются; открытое меню ботов не перекрывается меню `!pika`.

`slcreate` с произвольным текстом и удержание `+place_ad` остаются инструкциями в справке, а не ошибочным запуском без параметров. Снятие админского ограничения урона не отменяет результат голосования.

## Окно справки

Весь прежний каталог подсказок отфильтрован по плагинам и правам. Административный текст не отправляется игроку без соответствующего доступа. Закройте MOTD и используйте 6/7 для перелистывания либо напишите `!help 2`. Клавиша 8 возвращает `!pika`, 0 закрывает навигацию. Внешний сайт, JavaScript и подключение к Discord для окна не нужны.

Страница ограничена 1450 байтами — ниже [лимита MOTD в AMXX](https://github.com/alliedmodders/amxmodx/blob/master/plugins/include/amxconst.inc). HTML-символы экранируются; перенос страницы не разрывает UTF-8 или HTML-сущность. Длинные правила не обрезаются под размер одного окна.

## Установка

Скомпилировать `ultrahc_help.sma`, установить бинарник в `addons/amxmodx/plugins`, сохранив предыдущую версию. Имя остаётся `ultrahc_help.amxx`, отдельный плагин `pika` не нужен. В `plugins.ini` должна быть ровно одна строка `ultrahc_help.amxx` после `admin.amxx`, до обработчиков чата/Discord. Файл правил — в `addons/amxmodx/configs`.

Правила владелец пока не предоставил. Шаблон не содержит выдуманных правил; справка сообщает, что текст не опубликован. Добавлять UTF-8, по одному короткому правилу на строку, не более 320 байт; `;` и `#` начинают комментарий. Новый текст читается при следующей загрузке карты.

Источники тем: реальные объявления и регистрация команд сервера, исходники собственных дополнений. Справка охватывает меню ботов, статистику, голосование карты/проходов, общение, голосование ограничения исходящего урона, административное ограничение урона, редактирование надписей/рекламы. Неактивные или недоступные команды скрываются.

Нужны стандартные AMXX/amxmisc с `amxclient_cmd` (сервер проверялся на AMXX 1.9). `python -X utf8 test_ui.py` проверяет размеры/сохранность текста, экранирование и каталог действий; `--preview-dir <новый каталог>` создаёт примеры MOTD. Это проверки текстового контракта, не эмулятор Pawn и не доказательство вида окна в CS. После установки нужны проверка версии через `amxx plugins` и ручной вход игроком/администратором.

При сборке укажите стандартные include AMXX, абсолютные пути исходника и результата без расширения: `amxxpc.exe <путь к ultrahc_help.sma> -i<каталог_include> -o<путь результата без расширения> -E`. Локальный компилятор — 1.10.0.5461; предупреждения считаются ошибками благодаря `-E`.

Подсказка о ботах рассчитана на [Bot Control 1.3](../bot_control). В справке `/mute` описан как личное отключение голоса по исходнику ChatAdditions v1.9.1, а не как голосование из старого объявления.

Discord-бот, его конфиги и `ultrahc_discord.amxx` этим обновлением не заменяются. Здесь обрабатываются только служебные `!help`, `/help`, `!pika`, `/pika`; остальные сообщения передаются следующим обработчикам. Переход по чат-команде из меню использует ту же цепочку обработчиков, что ручной ввод.
