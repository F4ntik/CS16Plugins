# Bot Control 1.3

Контроллер ZBot с русским меню, основанный на исходнике Mep3ocTb и проверенном поведении установленной версии 1.1.

Команды `!bots`, `/bots`, `!bm` в общем/командном чате, `botmenu` в консоли игрока. Старые `!ba`, `!bk`, `!br` оставлены. После действий меню остаётся доступным для следующего выбора.

Добавление одного противника и выбор сложности доступны единственному человеку, выбравшему T или CT. Следующее добавление — после подтверждения предыдущего. Сложность 0–3 применяется к новым ботам; текущие боты не пересоздаются. Убийство/удаление ботов, как в живой версии 1.1, доступны всем подключённым людям.

Только во время явно начатой одиночной сессии боты удерживаются против человека, PTB временно приостанавливается, баланс команд отключается. При завершении сессии собственные изменения восстанавливаются. Люди не переводятся и не удаляются. Сохранено старое правило: отключение любого не-бота, включая зрителя/HLTV, удаляет всех ботов.

Нужны AMXX и стандартный модуль cstrike. Скомпилировать `botcontrol.sma`, установить как `addons/amxmodx/plugins/botcontrol.amxx`; существующая строка `botcontrol.amxx debug` остаётся. Нового конфига нет. Серверная команда `bc_status` только показывает состояние.

Проверено: компиляция AMXX 1.10.0.5461 без предупреждений (`-E`), загрузка на сервере AMXX 1.9.0.5294 и ответ `bc_status`. Меню и сценарии с человеком ещё требуют проверки игровым клиентом.

Сборка из папки дополнения: `amxxpc.exe botcontrol.sma -i<каталог_include> -obotcontrol -E`. Указывайте имя результата без расширения; будет создан `botcontrol.amxx`. Компилятор и его стандартные include устанавливаются отдельно.

Для общей справки игрокам можно также установить [меню !help](../server_help).
